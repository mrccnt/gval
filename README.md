# gval

CLI validator utilizing go-playground/validator.

## Description

`gval` utilizes [go-playground/validator](https://github.com/go-playground/validator) to allow simple, fast and relyable
validation of variables in bash/shell.

```shell
# Check string length and if it is an actual file
if ! gval "/file/not/found" "gt=0,lte=255,file"; then
  echo "invalid"
fi

# Check integer value range
if gval -i "8" "gte=5,lte=10"; then
  echo "ok"
fi

# Check if value is one of given options
if gval "1" "oneof=on off true false 1 0"; then
  echo "ok"
fi
```

## Return Codes

Let us keep it short:

| Code | About                                             |
|------|---------------------------------------------------|
| `0`  | Value matches pattern and options                 |
| `1`  | Value does NOT match pattern and/or options       |
| `2`  | Pattern is too long (255 chars) or invalid/unkown |

Any other kind of output generated by `gval` is a pure accident. My bad...
